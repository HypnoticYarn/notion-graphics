# notion-graphics

Every graphic in Cheryl's Graphics Library, hosted in one place so Notion pages, widgets and other tools can load them by URL. The working copies live in Google Drive at Claude Playground › 2nd Brain › Resources › Graphics (one folder per style set, rules in its README.md); this repo mirrors them. When a new graphics pack is sorted into the Drive library, add the same files here under the matching kebab-case folder.

Load any file with its raw URL: `https://raw.githubusercontent.com/HypnoticYarn/notion-graphics/main/<folder>/<file>`

## Style sets (from the Graphics Library)

One folder per style set; use graphics from one set per project so everything looks cohesive.

- **frog-and-snail** (149): the watercolor frog and snail garden set, in covers, icons, ui-icons, page-dividers, illustrated-dividers, botanical-dividers and source-sheets.
- **kawaii-brains** (20): flat pink kawaii brains with faces doing things.
- **kawaii-cute-friends** (9): soft kawaii characters and objects with blush faces.
- **line-doodles** (20): black hand-drawn line art.
- **signposts** (4): flat directional signposts.
- **hand-lettering** (2): black hand lettering phrases.
- **bees-soft-kawaii** (5): flatter, soft kawaii bees.
- **bees-cartoon-glossy** (11): glossy big-eyed cartoon bees.
- **team-avatars** (9): illustrated cartoon portraits of the Hypnotic Yarn team.

## Design elements

Neutral building blocks that can sit alongside any one style set.

- **speech-bubbles** (10): hand-drawn black-outline speech bubbles, thought clouds and burst bubbles.
- **device-mockups** (4): blank-screen iMac, MacBook, iPhone and line-outline phone frames.
- **glossy-pill-buttons** (3 files, 9 buttons): shaded pill buttons with soft shadows, three per file.
